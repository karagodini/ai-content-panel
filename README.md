# AI Content Panel

Простая веб-панель с чатом для контент-мейкеров: пишет посты, придумывает
заголовки и идеи, генерирует картинки. Работает на **бесплатном API
[Pollinations.ai](https://pollinations.ai) — ключ не нужен**.

![стек](https://img.shields.io/badge/FastAPI-009688) ![стек](https://img.shields.io/badge/vanilla_JS-f7df1e)

## Возможности

| Режим | Что делает |
|---|---|
| ✍️ Пост | Пишет готовый пост с хуком, призывом к действию и хэштегами |
| 🏷️ Заголовки | Даёт 5 вариантов цепляющих названий для соцсетей |
| 💡 Идеи | Предлагает 5 идей для постов и коротких роликов |
| 🖼️ Картинка | Генерирует изображение по текстовому описанию |

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Откройте http://localhost:8000

## Как это устроено

- `app/main.py` — FastAPI-бэкенд: один эндпоинт `/api/chat`, который
  проксирует запросы в `text.pollinations.ai` (текст) и
  `image.pollinations.ai` (картинки).
- `app/static/` — фронтенд без сборки: HTML + CSS + ванильный JS.
- Режим задаётся системным промптом — легко добавить свои режимы
  в словарь `MODES` в `app/main.py`.

## Ограничения

- У бесплатного API есть лимиты запросов; при частых обращениях возможны паузы.
- Генерация видео через бесплатный API без ключа пока недоступна —
  при необходимости подключите платный API (например, Runway / Kling)
  в тот же эндпоинт.
